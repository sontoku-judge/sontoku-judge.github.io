プライバシーポリシー

制定日：2026年10月1日

このポリシーは、YouTube チャンネル「ずんだもん損得ジャッジ」の運営者が使うアプリ「sontoku-judge」（以下「本アプリ」）における情報の取り扱いを定めるものです。

1. 本アプリの目的

本アプリは、運営者が自分の YouTube チャンネルに動画を投稿し、サムネイルや説明文を設定し、自分のチャンネルの再生数などの統計を確認するためだけに使います。

2. 取得する情報

本アプリは、Google のアカウント認証（OAuth）を通じて、運営者本人の YouTube チャンネルの情報（チャンネル名、動画の情報、再生数などの統計）にアクセスします。運営者以外の方の情報は取得しません。

3. 情報の利用と保存

取得した情報は、上記1の目的にだけ使い、運営者の端末にのみ保存します。第三者に提供、販売、共有することはありません。

4. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、限定使用の要件を含む Google API Services User Data Policy に従います。また本アプリは YouTube API サービスを使用しており、YouTube 利用規約と Google プライバシーポリシーが適用されます。

5. アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。
