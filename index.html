このサイトについて

このサイトは、YouTube チャンネル「ずんだもん損得ジャッジ」の案内ページです。チャンネルの運営者は、自分のチャンネルへの動画の投稿と、自分のチャンネルの再生数などの確認のために、YouTube Data API と YouTube Analytics API を使うアプリ「sontoku-judge」を使っています。このアプリは運営者本人のチャンネルだけに使い、ほかの方のアカウントには使いません。
